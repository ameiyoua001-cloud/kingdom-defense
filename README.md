# 王国防线：最后的城堡

**Kingdom Defense: The Last Castle** —— 原创中世纪奇幻风格的 2D 路线塔防网页游戏。

**在线试玩**：<https://ameiyoua001-cloud.github.io/kingdom-defense/>（GitHub Pages 自动发布，推送 main 分支即更新）

参考 Kingdom Rush 的经典玩法框架（路线行进、固定塔位、兵营拦截、波次召唤），但所有角色、地图、贴图、音效与 UI 均为本项目原创：贴图全部由代码程序化绘制，音效由 WebAudio 即时合成，不含任何第三方受版权保护素材。

## 技术栈

| 项 | 选型 |
| --- | --- |
| 游戏引擎 | Phaser 3（3.90.x 稳定版） |
| 语言 | TypeScript（strict 严格模式） |
| 构建 / 开发 | Vite 6 |
| 外围 UI | HTML5 + CSS |
| 数值 / 关卡配置 | JSON（`src/config/*.json`） |
| 本地存档 | LocalStorage（不可用时自动降级内存存档） |
| 单元测试 | Vitest（核心纯逻辑） |

无后端、无付费服务、无外部素材请求，可离线静态部署。

## 快速开始

```bash
npm install     # 安装依赖
npm run dev     # 本地开发（默认 http://localhost:5173）
npm run build   # 类型检查 + 生产构建（输出 dist/）
npm run preview # 预览生产构建
npm test        # 运行单元测试
npm run typecheck # 仅类型检查
```

`dist/` 使用相对路径打包，可直接放到任意静态托管的子目录。

## 第一阶段已实现内容

- 游戏主菜单（原创背景、标题动效）
- 世界地图（羊皮纸风格、关卡节点、星级显示、解锁逻辑，预留后续章节节点）
- 森林战斗地图「迷雾森林」：双出兵路径、12 个塔位、10 波敌人、终点城堡
- 四种防御塔（各 3 级）：
  - **猎鹰箭塔**：高射速物理输出
  - **秘法水晶塔**：魔法伤害，无视护甲
  - **矮人火炮**：范围溅射爆炸伤害
  - **王国兵营**：3 名士兵拦截敌人，可自由设置集结点
- 三种敌人：哥布林掠夺者（均衡）、恐狼（高速）、食人魔重锤兵（重甲高血量）
- 敌人沿折线路径移动、被士兵拦截后进入近战
- 炮塔自动索敌（优先最接近城堡的敌人）与追踪弹道
- 金币系统：击杀赏金、提前召唤下一波奖励
- 生命值系统：敌人漏过扣生命，归零失败
- 塔升级 / 出售（返还 60% 投入）
- 波次系统：手动召唤首波、间歇倒计时自动开波、提前迎战奖励
- 胜利 / 失败结算，按剩余生命评 1~3 星，本地存档记录最佳成绩
- 暂停、×1/×2 加速、音效开关
- 1280×720 逻辑分辨率，Phaser Scale Manager 等比缩放适配；手机横屏支持、竖屏旋转提示、安全区域处理

## 操作说明

| 操作 | 效果 |
| --- | --- |
| 点击木牌地基 | 打开建造轮盘，选择四种塔之一 |
| 点击已建塔 | 打开面板：升级 / 出售 /（兵营）设置集结点 |
| 设置集结点 | 在黄色圈内点击任意位置，士兵移防 |
| 右下角按钮 | 召唤下一波（间歇期提前迎战可得金币） |
| 右上角按钮 | 暂停、×1/×2 加速、音效开关 |

## 目录结构

```
├── index.html            入口页（含竖屏旋转提示层）
├── public/style.css      外围样式
├── src/
│   ├── main.ts           引擎初始化、缩放与方向适配
│   ├── types.ts          配置数据类型定义
│   ├── config/           塔 / 敌人 / 关卡波次 JSON 配置
│   ├── core/             纯逻辑：路径、伤害、波次、存档、音效、常量
│   │   └── __tests__/    Vitest 单元测试
│   ├── art/ArtGen.ts     程序化原创美术（全部贴图代码绘制）
│   ├── entities/         Enemy / Soldier / Tower / Projectile
│   ├── scenes/           Boot / MainMenu / WorldMap / Battle / HUD
│   └── ui/Widgets.ts     按钮、面板、提示等复用组件
└── docs/                 架构设计与开发路线文档
```

详细模块设计见 [docs/架构设计.md](docs/架构设计.md)，后续扩展计划见 [docs/开发文档.md](docs/开发文档.md)。

## AI 辅助开发约定

- 需求由玩家（项目负责人）提出并验收；代码设计、实现、调试、测试与文档由 AI 完成。
- 每次改动须通过 `npm run typecheck`、`npm test`、`npm run build` 三道门禁。
- 数值调整只改 `src/config/*.json`，不改逻辑代码。
- 新增内容遵循现有模块边界（详见架构文档），禁止把逻辑堆进单一文件。
