## 2. 已知边界与说明

- 世界地图第 2、3 关节点为占位（点击提示后续阶段开放），解锁逻辑已就绪。
- 音效为 WebAudio 合成的占位风格音效，第二阶段可替换为原创录制/采样音源，接口不变（`Sfx.*`）。
- 手机竖屏仅显示旋转提示，不做竖屏布局（需求约定横屏体验）。
- 平衡性初版数值基于 DPS/血量粗算，需按试玩反馈在 JSON 中迭代。

## 3. 数值调整指南

全部数值在 `src/config/`：

- `towers.json`：每级造价、伤害、攻速、射程、溅射、士兵属性。
- `enemies.json`：血量、移速、护甲/魔抗、赏金、扣命、近战攻击。
- `levels.json`：初始金币/生命、路径折点、塔位坐标、波次编成（enemy/count/interval/delay/path）。

改完直接 `npm run dev` 热更新生效，无需动逻辑代码。

新增关卡：在 `levels.json` 的 `levels` 数组追加同结构对象，再到 `WorldMapScene.nodes` 把对应占位节点的 `levelId` 换成新关卡 id 即可。

## 4. 第二阶段建议路线（待负责人确认优先级）

1. **内容扩展**：第 2 关（高地/雪原主题，新背景生成器参数化）、新敌人 2~3 种（飞行单位需新增防空规则）、Boss 波。
2. **塔进阶分支**：每塔满级后二选一转职（如箭塔→游侠巢/火枪堡），配置结构已预留 levels 数组可扩展 branch 字段。
3. **英雄单位**：可移动英雄 + 技能冷却栏（新增 entities/Hero + HUD 技能区）。
4. **主动技能**：陨石/增援两类全局技能（冷却 + 目标点选，复用集结点选点交互）。
5. **存档扩展**：设置页（音量滑条、画质）、成就统计。
6. **表现升级**：帧动画（骨骼/序列帧）、屏幕特效、原创 BGM。
7. **工程化**：E2E 冒烟（Playwright 驱动 Phaser 场景断言）、资源分包懒加载。

## 5. 开发流程约定（AI 辅助）

1. 负责人提需求 → AI 评估影响面（涉及哪些模块/配置）→ 实现。
2. 每次交付前跑三门禁：`npm run typecheck`、`npm test`、`npm run build`。
3. 新增纯逻辑必须带 Vitest 用例；实体/场景改动说明手动验证步骤。
4. 文档同步：架构变化更新 `架构设计.md`，阶段验收更新本文件。
5. 版权红线：不引入任何 Kingdom Rush 或其他游戏的素材/名称/造型复刻；一切美术音效原创或代码生成。
