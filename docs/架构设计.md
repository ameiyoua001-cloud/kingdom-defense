# 架构设计（第一阶段）

## 1. 总体分层

```
config(JSON) ──► core(纯逻辑) ──► entities(引擎实体) ──► scenes(场景编排)
                     ▲                                      │
                     └──────────── ui / art ◄───────────────┘
```

- **config**：纯数据。塔、敌人、关卡（路径/塔位/波次）全部 JSON 化，`src/config/index.ts` 做类型化导出。改数值不改代码。
- **core**：不依赖 Phaser 的纯逻辑（`PathFollower`、`Balance`、`WaveManager`），可被 Vitest 直接单测；`SaveManager`（LocalStorage 容错）、`Sfx`（WebAudio 合成）、`constants`。
- **entities**：依赖 Phaser 显示对象的运行时实体（Enemy / Soldier / Tower / Projectile），只关心自身行为，通过参数接收敌人列表等上下文，不直接摸场景全局。
- **scenes**：编排层。`BattleScene` 持有战局状态（金币/生命/实体列表），`HUDScene` 通过 `BattleAPI` 接口反向调用战斗操作，UI 与逻辑解耦。
- **art**：`ArtGen.ts` 在 Boot 场景一次性生成全部贴图（Graphics → generateTexture；战斗背景用离屏 RenderTexture 烘焙装饰物）。零外部图片。
- **ui**：按钮/面板/浮字等复用组件，统一视觉语言（粗描边 + 羊皮纸 + 木纹）。

## 2. 场景流转

```
Boot ─► MainMenu ─► WorldMap ─► Battle(+HUD 覆盖场景)
                         ▲            │ 结算/暂停面板
                         └────────────┘
```

- HUD 是独立覆盖场景，与 Battle 共用 1280×720 坐标系，天然对齐、无需坐标换算。
- Battle 在 `create()` 中 `scene.launch(HUD)` 并注入 `BattleAPI`；HUD `create()` 末尾补一次 `refresh()`，两个方向的启动时序都安全。
- 重开 = `scene.stop(HUD)` + `Battle.scene.restart({levelId})`；状态全部在 `init()` 重置，无残留。

## 3. 关键机制

### 3.1 路径与移动
- 关卡配置多条折线路径（`Vec2[][]`），敌人出生时绑定其一。
- `PathFollower` 按弧长推进，提供坐标、朝向、`remaining`（剩余路程）。
- 炮塔索敌规则：射程内取 `remaining` 最小者（最接近城堡优先）。

### 3.2 拦截与近战
- 兵营塔持有 3 名 `Soldier`，围绕集结点小三角站位。
- 敌人进入集结点 46px 内且无人拦截 → 被最近士兵锁定（`enemy.blocker`），双方站定互殴。
- 士兵追击超出集结点 110px 拴绳即放弃；士兵阵亡后兵营按配置秒数补员。
- 集结点限制在兵营 `rallyRadius` 圆内，越界点击自动夹取到圆边。

### 3.3 伤害模型
- `computeDamage(base, kind, armor, magicResist)`：physical/explosive 吃护甲，magic 吃魔抗，减免上限 90%，保底 1 点。
- 火炮命中点半径 `splash` 内全体结算；弹道目标死亡后箭/魔法弹消散，炮弹仍飞向最后位置爆炸。

### 3.4 波次调度
- `WaveManager` 状态机：`idle → spawning → break → … → allSpawned`。
- 首波手动；间歇 14s 自动开下一波；提前迎战按剩余秒 ×2 奖励金币。
- 全部波次出完且场上无敌人 → 胜利；生命归零 → 失败。

### 3.5 经济与存档
- 初始金币/生命来自关卡 JSON；击杀得赏金；出售返还 60% 累计投入（向下取整）。
- 星级：剩余生命 ≥90% 三星、≥50% 两星、其余一星；`SaveManager` 只保留更好成绩。
- LocalStorage 键 `kingdom-defense-save-v1`，解析失败/隐私模式自动降级，不影响游戏。

### 3.6 适配
- `Phaser.Scale.FIT + CENTER_BOTH`，逻辑分辨率恒为 1280×720，等比缩放不裁切。
- 触屏竖屏时 DOM 覆盖层提示旋转（`pointer: coarse` + `orientation: portrait`）。
- 容器 padding 使用 `env(safe-area-inset-*)` 处理刘海屏。
- 交互按钮命中区 ≥42px（逻辑像素），手机上缩放后仍便于点按。

## 4. 性能约定

- 战斗背景一次性烘焙为单张贴图，装饰物不占运行时对象。
- 血条用共享 Graphics 按需重绘；粒子发射器用完即毁。
- 实体数组每帧过滤死亡项；弹道数量级为个位数~几十，无需对象池（第二阶段如加弹幕再引入）。
- `update` 中 dt 上限 0.05s，×2 加速通过 dt 缩放实现，切后台不会跳帧穿路。

## 5. 测试与质量门禁

- `npm run typecheck`：TS strict + noUnusedLocals/Parameters。
- `npm test`：PathFollower / 伤害 / 经济星级 / WaveManager 共 13 个用例。
- `npm run build`：tsc + vite build 双检。
- 约定：任何改动三门禁全绿才可交付。
